# Trocar o endereço de entrega

Depois que o pedido foi feito, não é possível trocar o endereço pelo app. Isso evita fraudes e mudanças no valor da entrega.

Se você digitou o endereço errado, fale com o suporte pelo chat o quanto antes. Se o restaurante ainda não confirmou o pedido, o suporte pode cancelar sem custo para você refazer com o endereço certo.

Para a mesma rua ou o mesmo prédio, você pode mandar uma mensagem ao entregador pelo chat do pedido, com complemento ou ponto de referência.

Para salvar vários endereços, como casa e trabalho, use **Perfil > Endereços**.

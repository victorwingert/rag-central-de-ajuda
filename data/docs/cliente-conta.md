# Alterar dados ou excluir a conta

## Alterar e-mail ou telefone
Vá em **Perfil > Dados da conta**. Para trocar o telefone, o app envia um código por SMS para o número novo. Para trocar o e-mail, o código vai para o e-mail antigo e para o novo.

## Excluir a conta
Em **Perfil > Dados da conta > Excluir conta**. A exclusão é definitiva depois de 30 dias. Nesse período você pode desistir entrando de novo no app.

Antes de excluir, use o saldo da carteira: saldo não usado é perdido na exclusão. Pedidos em andamento precisam estar concluídos.

Os dados de pedidos são mantidos pelo prazo exigido pela lei fiscal, mesmo após a exclusão.
